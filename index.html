模型与算法

需求生成乘客到达间隔服从泊松过程；λ 是到达率（人/分）。
Δt = −ln(1−U) / (λ / 60)
预计到达时间以路线距离、计划停靠和当前载客量估计每台车对一个楼层请求的响应代价。
T̂ₑ(f) = d_route / v + n_target(t_door + c) + n_rider·w
派梯与容量约束对每组“楼层 + 方向”请求，选择预计时间最小的轿厢；同时满足载客数不超过 C。
e* = arg minₑ T̂ₑ(f),   ridersₑ ≤ C
两种目标响应优先降低接人时间；节能优先给新增停靠与逆向请求更高代价，以减少距离和停靠。
J_response ≈ T̂ₑ(f)   |   J_energy ≈ T̂ₑ(f) + α·stops + β·empty_distance

现实参数对应：到达率 λ、速度 v、开门时间 t_door、轿厢容量 C、楼层数 F。切换到此处不会暂停或重置左侧正在运行的仿真；这里使用规则式启发式，适合用于解释和比较，不代表真实楼宇控制器的全局最优结果。
